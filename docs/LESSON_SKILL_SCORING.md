# 课次技术点评分（P0 数据基础）

## 目标与边界

- 自动从现有24个教学单元的 `kp`（关键判据）生成48课次评分项目。
- 奇数课次映射A新授，偶数课次映射B巩固；课次主线不变。
- 每个评分项目使用0–5分通用锚点，并保留原始课程判据作为本项观察依据。
- 阶段考核 `assessments` 的7项指标与晋级阈值逻辑保持独立。
- 未评分与0分严格区分；0分表示已评估但无法完成，不表示缺失。

## 数据来源和生成规则

对第n教学单元，读取课程种子中的 `kp` 字段，以 `|` 分隔成关键判据。每个判据生成稳定技术键 `uNN_kpNN`，分别关联到第(2n-1)课A新授和第2n课B巩固。A/B课分别保存 `a` / `b` 作为本课焦点说明。此阶段不从自由文本推断新技术，也不改写课程原文。

## 0–5分通用锚点

| 分数 | 含义 | 通用描述 |
|---:|---|---|
| 0 | 无法完成 | 在安全、可执行的基础条件下尚不能完成；安全风险则停止测试并记录 |
| 1 | 需要持续协助 | 需要教练逐步提示或协助，大部分时间未达到判据 |
| 2 | 部分完成 | 降低速度/难度或提示后部分达到，仍不稳定 |
| 3 | 基本达到 | 标准练习条件下基本达到，仍有可识别偏差 |
| 4 | 稳定达到 | 标准条件下稳定达到，偶有偏差且能自行调整 |
| 5 | 灵活运用 | 在变化来球、节奏或对抗情境中稳定达到并合理运用 |

通用锚点不是各技术的最终专项量表。评分时必须同时查看原始判据；后续迭代应由教练校准各技术点的专项描述。

## 新增表

- `skill_definitions`: 稳定技术点及评分标准版本。
- `lesson_skill_points`: 48课次与技术点映射。
- `plan_skill_points`: 生成教案时冻结评分项目和评分标准快照。
- `session_skill_scores`: 学员单堂课评分明细，含可选尝试/成功次数。
- `sessions.plan_id`: 授课记录关联实际教案。

## 兼容与安全

迁移只新增字段和表，不删除或重写旧表；`assessments` 不变。评分明细关联本堂 `sessions` 与教案快照。尝试次数和成功次数允许为空；若填写成功次数则必须同时填写尝试次数且成功数不得大于尝试数。评分必须为0–5整数。

## 当前实现范围

本阶段新增数据库结构与从既有课程关键判据生成映射的种子模块。教案生成时快照、课后评分界面、趋势和下一课动态调整尚未接入，不应在此版本中视为已可用功能。
