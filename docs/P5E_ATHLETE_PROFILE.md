# P5-E 学员能力画像与成长证据链

## 目标
将课堂形成性评分、阶段能力评估、教练复核、补训计划和复测记录整合为可追溯的学员成长画像。该画像用于教练复盘与教学决策，不自动晋级。

## 数据来源与口径
- 学员基础档案：当前阶段、48课次进度、年龄组、目标和安全备注。
- 课堂技术成长：读取 `session_skill_scores` 与 `plan_skill_points`，沿用0–5评分、最近分、近三次均分、趋势和薄弱/掌握状态。
- 阶段能力评估：读取版本化协议快照、单项0–4评分、教练复核状态、观察记录、尝试记录和证据引用。
- 补训与复测：读取补训计划、能力项、目标课次/技术点、计划状态和复测关联。
- 授课轨迹：最近授课、出勤、RPE、判据和教练反馈。

## API
`GET /api/v1/students/:id/athlete-profile`

响应分区：
- `overview`：课程进度、课堂评分数量、薄弱/掌握技术点数、授课和出勤摘要。
- `skillDevelopment`：每个技术点的状态、最近分、近三次均分、趋势及原始历史。
- `stageAssessments`：每次评估/复测的协议版本、状态、单项结果、复核与证据。
- `stageSummary`：按初/中/高阶汇总最近评估、必测缺项与待复核项。
- `remediationPlans`：补训计划及能力项状态、映射课次/技术点和训练说明。
- `recentSessions`、`timeline`：授课与评估、补训事件时间线。
- `evidence`：授课、评分、评估、复核和证据记录数量。
- `interpretation`：量表口径与数据限制。

## 教练端
学员详情增加“能力画像”入口，展示课堂技术成长、阶段评估、补训状态、证据完整度和成长时间线，并支持导出画像JSON。

## 专业边界
1. 课堂0–5与阶段0–4分开呈现，不换算、不合并为单一总分。
2. 草案/试测协议的结果仅用于证据积累；不产生自动晋级结论。
3. “稳定掌握/薄弱项”仅描述已有评分历史，不代表所有比赛情境中的稳定能力。
4. 未录入、未观察、缺少录像或缺少尝试数据均应视为证据不足，不按失败处理。
5. 年龄、伤病备注和RPE作为教练安全复盘信息，不作医疗诊断。
6. 报告是教学决策支持，不替代教练观察、标准化试测或晋级评审。

## 后续校准
- 逐项人工核验阶段能力与48课次技术点映射，减少关键词匹配误差。
- 统一录像命名、拍摄角度、测试条件、证据引用规范。
- 试测期安排两名教练共同评分，统计一致性后再讨论协议发布。
- 在真实学员样本上验证评分分布、测试负担和复测灵敏度；未校准前不设置自动通过线。
